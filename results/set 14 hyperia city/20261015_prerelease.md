# Card Club - Card Club - Hyperia City Prerelease - Mitternachtsevent

Set 14 Hyperia City pre release event in Card Club. In total 19 showed up to play in a event with format Sealed. Tracking via https://tcg.ravensburgerplay.com/events/1007147.

## Card Club - Meta Report

### Spieler 19

All players on sealed decks from the pre release pack.
